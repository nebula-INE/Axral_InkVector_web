# 実装計画: キャンバスサイズ自由指定・プリセット選択・余白中央拡張リサイズ機能

ユーザーの要望に基づき、商業誌・SNS・Webtoonなどの豊富なプリセット選択と数値直接入力、および描画内容を中央維持したままキャンバス余白を拡張・縮小できる「キャンバス設定・新規作成システム」を実装します。

---

## 1. 提案する機能の全体像

1. **キャンバスサイズ設定＆新規作成モーダル (`CanvasSizeModal.tsx`)**
   - **2つのモード切替**:
     - 「現在のキャンバスサイズ変更 (リサイズ)」: 既存の描画内容を維持したまま、キャンバスの枠（解像度）を変更。
     - 「新規キャンバス作成」: 指定サイズで白紙キャンバスを新規作成。
   - **商業規格＆Webプリセット集**:
     - **漫画・同人誌**: B5商業誌原稿 (2570×3640), A4カラー (2894×4093), A5本 (1748×2480), B5縮小 (1820×2570)
     - **イラスト・SNS**: Full HD 16:9 (1920×1080), 4K UHD (3840×2160), 正方形 1:1 (1080×1080), スマホ 9:16 (1080×1920), Xヘッダー 3:1 (1500×500)
     - **Webtoon (縦スクロール)**: 標準 (800×4800), ロング (800×9600)
   - **数値直接入力**:
     - 幅 (px) と 高さ (px) の自由入力
     - 縦横比固定リンク（アスペクト比ロック 🔗）
     - 縦向き / 横向き ワンクリック反転 (⇄)
   - **リアルタイム縮尺プレビュー**:
     - 新しいキャンバス比率と、既存の絵が中央にどう配置されるかをビジュアル表示。

2. **中央基準の余白拡張・縮小エンジン (`geometry.ts` / `App.tsx`)**
   - キャンバスサイズ変更時（例: 1920×1080 → 2570×3640）:
     - 差分 `dx = (newW - oldW) / 2`, `dy = (newH - oldH) / 2` を計算。
     - 全レイヤーの既存ベクターノード位置、制御点、フキダシ尾の位置を `+dx, +dy` 平行移動。
     - 対称定規中心 `symmetryCenter` やパース消失点も新しい中央に自動再配置。
     - これにより、描いた絵がずれることなくキャンバスの余白だけが均等に拡張・トリミングされます。

3. **直感的なUIアクセス**
   - **ヘッダー**: 現在のキャンバスサイズ表示（例: `1920 × 1080px`）をクリックして即座にリサイズダイアログ起動。
   - **ヘッダー「新規」ボタン**: 新規キャンバス作成ダイアログを開き、サイズを選んで白紙開始。
   - **フッターのステータス情報**: `1920 × 1080px` をホバー・クリック可能にして素早くサイズ変更。

## 2. 変更対象ファイル

1. **新規作成**: `/src/components/CanvasSizeModal.tsx`
   - プリセット選択タブ（漫画/同人誌、イラスト/SNS、Webtoon）
   - 幅・高さの入力フォーム（縦横比固定・向き切替）
   - キャンバス比率プレビュー＆変更前後の配置プレビュー
   - リサイズ実行 / 新規作成実行
2. **更新**: `/src/utils/geometry.ts`
   - `offsetDocumentContent(doc: Document, dx: number, dy: number): Document`: 全レイヤーのノード・制御点・フキダシ位置を中央シフトするユーティリティ関数
3. **更新**: `/src/components/Header.tsx`
   - キャンバスサイズバッジ（クリックでモーダル表示）
   - 「新規」ボタン押下時にモーダル（新規作成モード）を起動
4. **更新**: `/src/App.tsx`
   - `isCanvasSizeModalOpen` 状態管理
   - キャンバスリサイズハンドラー（中央オフセット適用＆自動画面フィット）
   - フッターのキャンバスサイズバッジをクリック可能化

---

## 3. 検証計画

- **プリセット選択動作**: B5商業誌、A4、正方形、Webtoonを選択した際に正しいピクセル寸法が反映されるか。
- **数値入力＆縦横比ロック**: 幅を変更した際にアスペクト比固定が機能するか。縦横向き反転が正確か。
- **既存描画の中央維持**: 描いたキャラクターや線画がある状態でサイズ変更を行い、絵が歪んだりずれずにキャンバス中央を保っているか。
- **ビルド・コンパイルチェック**: `compile_applet` および `lint_applet` による検証。
